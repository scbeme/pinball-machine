# cad

Mechanical CAD: native files (MoI3D `.3dm`) and STEP exports (`.stp`). CAD controls geometry and device counts.

File naming: `<device id>-<device name>-<yyyymmdd-##>.<ext>`, hyphenated lowercase, no spaces or parentheses.
Example: `DC-05-drop-target-bank-7-20261105-01.stp`. The playfield also uses a device ID.
