# GoHz M12 inductive proximity sensor (common component)

**Revision:** 20261106-01 · **Used by:** DP-18 Rollover sensor (including the outlane sensors that trigger DC-03 Outlane save gate/deflector), DB-01 Scoop/hole, DB-03 Ball trough, DB-04 Shooter lane ball-present sensor

Common electrical interface: 24 V supply, NPN output to a Topedal direct (or matrix) switch input, GND to GNDREF. Inductive sensing is immune to magnetic fields from nearby solenoids and magnets, so no shielding or magnetic keep-out distance is required.
